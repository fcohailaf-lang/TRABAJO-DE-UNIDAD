# Sistema de Gestión Bibliotecaria - UNJBG

## Descripción

Este proyecto consiste en el desarrollo de una aplicación en C++ que simula un sistema de gestión bibliotecaria para la Biblioteca Central de la Universidad Nacional Jorge Basadre Grohmann (UNJBG).

El sistema permite administrar información relacionada con libros, usuarios y préstamos, facilitando el control de los recursos bibliográficos disponibles.
